# PCForge - PC Builder & Components Store

Demo website for the FPT Polytechnic "Lập trình cơ sở với Javascript" Assignment.

## Chạy project
Mở `index.html` bằng trình duyệt hoặc dùng VS Code Live Server.

## Chức năng
- Product data bằng array/object
- New / Hot / Sale
- Category
- Search / Filter / Sort
- JavaScript slider
- Countdown
- Product detail
- Cart: add/remove/quantity
- LocalStorage cart
- Checkout validation
- PC Builder
- Compatibility checker
- Save / Load Build bằng LocalStorage
- Add Build to Cart
- Responsive UI
